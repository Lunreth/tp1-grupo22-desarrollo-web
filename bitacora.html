PROCESO DE DESARROLLO

Bitácora

Registro de decisiones, dificultades y cambios realizados durante el proyecto.

01

PLANIFICACIÓN

Organización del equipo

Definimos roles, tareas, tiempos de trabajo y una forma de comunicación compartida antes de comenzar a desarrollar.

02

DISEÑO

Identidad visual

Elegimos una estética basada en tarjetas, contraste, tipografías modernas y sombras para generar profundidad.

03

DESARROLLO

HTML + CSS + JavaScript

Construimos páginas semánticas, una hoja de estilos compartida y funciones JavaScript para generar interacción.

04

RESPONSIVE

Pruebas en distintos tamaños

Revisamos la adaptación del sitio para los breakpoints obligatorios de 400 px, 900 px y 1200 px.

05

PUBLICACIÓN

GitHub + Vercel

El repositorio será público, independiente y contará con la documentación requerida. La publicación final se realizará mediante Vercel.

06

USO DE IA

Asistencia y revisión

La IA se utilizó como asistente para apoyar código, diseño y debugging. El equipo debe documentar qué herramientas utilizó, qué resultados adaptó y qué decisiones tomó de manera propia.

PENDIENTE DE COMPLETAR

Registro real del proceso

Antes de entregar, reemplazar los textos generales por las decisiones, problemas y soluciones que realmente hayan ocurrido durante el desarrollo.
